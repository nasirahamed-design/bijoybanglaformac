Bijoy Bangla is ready

In a moment বাংলা (বিজয়) switches on by itself. Then start typing in any app.

  • Switch between Bangla and English with Control-Space, or from the input menu near the clock in the top bar.
  • If বাংলা (বিজয়) is not in the input menu yet, log out and back in once.

If the input menu isn't showing at all, open System Settings > Keyboard > Input Sources > Edit… and turn on Show Input menu in menu bar. The full steps are in Activation Guide.pdf in the download.
