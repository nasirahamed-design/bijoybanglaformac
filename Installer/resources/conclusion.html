If macOS asked "Allow Bijoy Bangla to enable Bijoy Bangla?", make sure you clicked Allow.

Click Log Out, then after you log back in:

  1. Click the input menu near the clock in the top bar.
  2. Choose বাংলা (বিজয়) and start typing.

Switch between Bangla and English with Control-Space. If the input menu isn't showing at all, open System Settings > Keyboard > Input Sources > Edit… and turn on Show Input menu in menu bar. The full steps are in Activation Guide.pdf in the download.
