Questions

Is it really free?

Yes. No trial, no account, no ads. The source code is open on GitHub under the MIT licence.

Will my text work on websites and Facebook?

Yes. It types standard Unicode Bangla, so it shows correctly in browsers, Word, Pages, WordPress, Facebook and with any Bangla font. It does not use the old SutonnyMJ-style encoding.

Why isn't it on the Mac App Store?

Apple does not allow keyboards (input methods) in the Mac App Store. This download is signed with a Developer ID and checked by Apple (notarized), so it opens without security warnings.

Why is there no keyboard picture in System Settings?

macOS only draws that picture for simple keyboard layouts. Bijoy Bangla is an input method, which is what lets it place ি before the letter and build যুক্তাক্ষর, so macOS shows a notice there instead. To see the keys, choose Show Bijoy Keyboard Layout from the input menu in the top bar.

How do I uninstall it?

Click the input menu in the top bar, choose Uninstall Bijoy Bangla, enter your Mac password, then log out and back in.

Something typed wrong. How do I report it?

Open an issue on GitHub with the keys you pressed and the word you expected.
