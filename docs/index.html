A familiar Bijoy keyboard for Mac

Bijoy Bangla for Mac is a free, open-source Bangla input method for macOS, built around the familiar Bijoy layout. Type in Microsoft Word, Pages, Google Docs, Safari, Chrome, Facebook, WhatsApp, Messenger, Gmail and other Mac apps.

Choose Bijoy Unicode for standard Unicode Bangla in websites, email, social media and documents you share. Choose Bijoy Classic for classic Bijoy text used with SutonnyMJ and other MJ fonts in print and desktop-publishing workflows, including Word, InDesign, Illustrator and QuarkXPress.

Compatible with macOS 13 Ventura and later, including macOS 14 Sonoma, macOS 15 Sequoia and macOS 26 Tahoe, on Apple silicon (M1, M2, M3 and M4) and Intel Macs. The installer is signed with a Developer ID and notarized by Apple. The project is released under the MIT licence.

Questions

Is it really free?

Yes. It is free to use, with no trial, account or ads. Its source code is available on GitHub under the MIT licence.

Will Bangla text display correctly online?

Yes. বিজয় ইউনিকোড produces standard Unicode Bangla, which is supported by browsers, Word, Pages, WordPress, Facebook and other apps that display Bangla text.

Can I use SutonnyMJ for print work?

Yes. Select বিজয় ক্লাসিক from the input menu and set your document to SutonnyMJ or another MJ font. Type with the familiar Bijoy keys to produce classic Bijoy text for compatible fonts and print workflows. For websites and email, use বিজয় ইউনিকোড.

Which Macs and macOS versions are supported?

macOS 13 Ventura or later, including macOS 14 Sonoma, macOS 15 Sequoia and macOS 26 Tahoe, on Apple Silicon (M1, M2, M3, M4) and Intel Macs.

Why is it distributed outside the Mac App Store?

Bijoy Bangla for Mac is distributed directly from this website. Its installer is signed with a Developer ID and notarized by Apple. macOS verifies the installer when you open it.

Why does System Settings not show a keyboard diagram?

System Settings shows diagrams for standard keyboard layouts. Bijoy Bangla is an input method that handles Bangla vowel signs and যুক্তাক্ষর, so macOS may show an information notice instead of a diagram. To view the keys, open the input menu in the menu bar and select “Show Bijoy Keyboard Layout.”

How do I uninstall it?

Open the input menu in the menu bar and select “Uninstall Bijoy Bangla.” Enter your Mac password when prompted, then log out and sign back in.

How can I report a typing issue?

Please open an issue on GitHub and include the keys you pressed and the Bangla text you expected.
