Bijoy Bangla বিজয় বাংলা

Activation Guide · Type Unicode Bangla on your Mac with the Bijoy keyboard layout

You need a Mac with macOS 13 Ventura or later (Apple Silicon or Intel) and your Mac login password. Installing takes about two minutes, including one log out.

1. Install

  1. Double-click BijoyBangla-x.x.x.dmg in your Downloads folder. A window opens with two files.
  2. Double-click Install Bijoy Bangla.pkg.
  3. Click Continue, then Install. Enter your Mac password when asked.
  4. If macOS asks "Allow Bijoy Bangla to enable Bijoy Bangla?", click Allow.
  5. When the installer says it is finished, click Log Out (save any open work first), then log back in. macOS loads a new keyboard at login.

2. Turn it on

  1. Look for the input menu in the top bar, near the clock (a small icon such as A or a flag). If you can see it, skip to step 5.
  2. Otherwise open Apple menu > System Settings > Keyboard.
  3. Under Text Input, click Edit… next to Input Sources.
  4. Turn on Show Input menu in menu bar. Check that বাংলা (বিজয়) is in the list on the left. If it is missing, click +, choose Bangla, select Bijoy Bangla and click Add. Click Done.
  5. Click the input menu and choose বাংলা (বিজয়). The icon changes to বা.
  6. Open TextEdit and type hfQVf. You should see বাংলা.

3. Switch between Bangla and English

WayHow
KeyboardPress Control-Space to flip between the last two input sources. On newer Macs the 🌐 (Globe) key does the same.
Top barClick the input menu and choose বাংলা (বিজয়) or English.
If Control-Space does nothing, open System Settings > Keyboard > Keyboard Shortcuts > Input Sources and tick Select the previous input source.

4. Typing with Bijoy

The word you are typing appears underlined. It is finished when you press Space, Return, punctuation or click elsewhere. Backspace corrects the word you are still typing. For a full picture of the keys, choose Show Bijoy Keyboard Layout… from the input menu.

5. Troubleshooting

ProblemFix
বাংলা (বিজয়) is not in the listLog out and back in once. Then repeat section 2.
No input menu in the top barTurn on Show Input menu in menu bar (section 2, step 4).
Letters come out wrongCheck the input menu shows বা, not English or ABC.
Text shows boxes or broken lettersThe app's font has no Bangla. Choose a Bangla font such as Kohinoor Bangla or Noto Sans Bengali.
No keyboard picture for বাংলা (বিজয়) in System SettingsNormal. macOS only draws that picture for simple layouts, not input methods. Choose Show Bijoy Keyboard Layout… from the input menu to see the keys.
Installer says it can't be openedDownload the DMG again from the official website. Do not use copies from other sources.

6. Uninstall

Click the input menu and choose Uninstall Bijoy Bangla…, then enter your Mac password. Log out and back in to finish.
